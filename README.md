# Banking and Loan Risk Analysis

## Project Overview
This project analyzes banking and loan data using Python and Exploratory Data Analysis (EDA). It helps understand customer loan behaviour and factors related to loan defaults.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project Steps
1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. KPI Calculation
5. Data Visualization
6. Key Findings and Conclusion

## Key Analysis
- Total loan applications
- Average loan amount
- Customer income analysis
- Loan default percentage
- Loan purpose analysis
- Credit risk patterns

## Dataset
Credit Risk Dataset from Kaggle:
https://www.kaggle.com/datasets/laotse/credit-risk-dataset

## Conclusion
This project uses data analysis and visualizations to understand loan default patterns and credit risk, supporting better banking risk analysis.
